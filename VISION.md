# AttackLens AI (formerly SOC-AgentLab)

**Tagline**: “The AI Copilot for Security Investigations”

**Alternative Names**: ThreatGraph AI, HuntFlow, ShadowTrace, IncidentGPT, TriageAI, BreachLens, SentinelMind

## Core Vision
Build a next-generation open-source AI-native SOC investigation platform that transforms raw logs and alerts into:
- Visual attack stories
- Conversational investigations
- Cinematic attack replays
- MITRE ATT&CK mappings
- Autonomous investigation guidance
- Intelligent false-positive analysis
- Human-readable incident narratives

This is an AI-powered incident understanding engine designed to help humans instantly understand cyber attacks.

## Core Problem
SOC teams suffer from alert fatigue, fragmented investigations, and lack of contextual understanding. This platform solves: “Upload logs → instantly understand what happened.”

## Core Product Pillars
1. AI Incident Reconstruction
2. Conversational Investigation
3. Visual Attack Intelligence
4. AI-Assisted Threat Hunting
5. Autonomous Investigation Guidance
6. Human-Centered Security UX
7. Analyst Productivity Acceleration
8. Cinematic Investigation Experience

## Feature Set
- **AI Incident Reconstruction Engine**: Analyze logs, correlate events, infer intent.
- **Conversational AI Investigation**: Chat with logs like a senior SOC analyst copilot.
- **Attack Timeline Engine**: Interactive, animated, and cinematic event sequences.
- **Attack Graph Engine**: Process trees, lateral movement maps, glowing nodes.
- **MITRE ATT&CK Intelligence**: Automatic mappings and heatmaps.
- **False Positive Intelligence Engine**: Contextual confidence scoring.
- **Beginner → Expert Explanation Engine**: Adaptable explanation complexity.
- **Natural Language Threat Hunting**: "Find suspicious PowerShell."
- **Autonomous Investigation Guidance**: Proactive next steps.
- **Investigation Memory Engine**: Contextual intelligence across incidents.
- **Attack Replay / Cinematic Mode**: Viral, visual playback of attacks.
- **AI-Generated Investigation Reports**: Polished, exportable summaries.
- **One-Click Demo Mode**: Instant "wow" factor for GitHub stars.
- **Built-in Attack Labs**: Realistic datasets (ransomware, C2, etc.).

## Tech Stack (Target Architecture)
- **Frontend**: Next.js, React, TypeScript, TailwindCSS, Framer Motion, Cytoscape.js / D3.js
- **Backend**: Python FastAPI, LangChain / LangGraph
- **Databases**: PostgreSQL, Qdrant/ChromaDB, Redis/RabbitMQ
- **Deployment**: Docker Compose, Kubernetes-ready
